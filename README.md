# Workaway Home Assistant apps

## WiFi Portal Agent

Connects a UniFi console's guest portal to a central sign-in portal. It serves the portal to guests through Home Assistant and authorises their devices on the local UniFi console.

To install it, go to **Settings → Apps → Install app → ⋮ → Repositories** and add this repository's URL. Then install **WiFi Portal Agent** and fill in its configuration. Keys and passwords belong in that configuration, never in this repository.
